## How to Run

### Step 1 – Make folders reqiured

1. Make a folder in your pc named "AI Project"
2. Now download both python file - "main.py" and "admin.py".
3. Move those files to the folder you just created from downloads.
4. Now open "Command Prompt" of your pc.
5. Now run this line of command in it `pip install opencv-python numpy`.
6.If any issue comes up please check your python istallation in your pc and cross check the pip calls in your pc.
7.Now first run the "admin.py" first before "main.py".
8.After setup and adding students you can run "main.py" and check out the project.
